# Nexus Chess

A fully offline chess game for the browser. Play vs the computer (5 levels) or a friend on one device, with clocks, hints, puzzles, lessons, PGN/FEN, stats and game review. Installable as a PWA.

Files: `index.html`, `manifest.json`, `sw.js`, `icon.svg`.

Deploy: GitHub repo -> Settings -> Pages -> Deploy from branch `main` / root.
